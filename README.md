Project: CrackVision AI – Concrete Crack Detection System

I developed a project called CrackVision AI, which is an AI-powered concrete crack detection application using Computer Vision and Deep Learning.

The main objective of this project is to automate the identification of visible cracks in concrete structures such as buildings, bridges, roads, columns, and beams.

Traditionally, civil engineers inspect concrete structures manually, which can be time-consuming and may result in missing small cracks.

To solve this problem, I developed an AI-based application where users can upload concrete surface images. The trained AI model analyses the uploaded image and detects potential cracks.

I also implemented inference controls such as confidence threshold, NMS IoU threshold, image size, and maximum detections to control the model's prediction behaviour.

I used Python and Streamlit to develop the application interface and deployed it as a web application.

Real-world applications: Building inspection, bridge maintenance, highway inspection, tunnel monitoring, and infrastructure maintenance.

My main objective: To combine my Civil Engineering knowledge with Artificial Intelligence to develop a practical solution for infrastructure inspection.
