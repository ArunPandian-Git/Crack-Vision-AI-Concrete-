# CrackVision AI

## Intelligent Concrete Crack Detection
and Segmentation System

### Project Overview

CrackVision AI is a Deep Learning-based
application designed to detect and segment
cracks in concrete structures using
Computer Vision.

### Technologies

- Python
- PyTorch
- YOLOv8 Segmentation
- OpenCV
- NumPy
- Streamlit

### Features

- Concrete crack detection
- Image segmentation
- Crack coverage calculation
- Confidence visualization
- Image analysis
- Inspection report generation

### Project Architecture

- dataset: Training and testing images
- models: Deep Learning model weights
- notebooks: Data exploration
- src: Python source code
- results: Prediction outputs
- app.py: Streamlit application

### Installation

pip install -r requirements.txt

### Run Application

streamlit run app.py
